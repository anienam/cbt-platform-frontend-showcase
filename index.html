MY CONTRIBUTION

More than a set of screens.

The work involved building interfaces for people with different responsibilities, while keeping the experience clear and consistent across the platform.

01

Interface development

Built page layouts, navigation, forms, tables, dashboard sections and reusable interface patterns.

02

Interactive examination flows

Implemented frontend interactions including timers, question navigation, answer selection, auto-save behaviour and submission feedback.

03

Role-specific dashboards

Structured separate experiences around the tasks of students, teachers, principals and administrators.

04

Responsive implementation

Adapted layouts and components for desktop, tablet and smaller screens, with attention to usability and navigation.
