# CBT Student Dashboard

A modern, responsive frontend for a Computer-Based Testing (CBT) platform designed for students.

## Features

- Authentication
- Student Dashboard
- Profile
- Exam Interface
- Timer
- Question Navigation
- Auto-save UI
- Results Screen
- Responsive Design

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

> This repository contains only the frontend implementation. Backend services and APIs are maintained separately in the company's private repository.
